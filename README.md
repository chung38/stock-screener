# 三重共振選股

找「基本面爆發＋籌碼進駐＋技術面突破」同時成立的台股，另外在大盤恐慌時列出營收仍強、股價卻被錯殺的股票。資料全部來自證交所、櫃買中心、公開資訊觀測站、集保結算所的免費公開資料，抓下來後存在自己的伺服器上累積。

## 篩選邏輯

| 支柱 | 條件（預設，可在畫面左側調整） | 資料來源 |
|---|---|---|
| 基本面 | 近 3 個月營收年增率**每個月**都 > 20% | 證交所／櫃買 OpenAPI 月營收、觀測站回補 |
| 基本面 | 單季毛利率連續 2 季改善（Q-2 < Q-1 < Q） | 營益分析（累計數，系統自動相減還原單季） |
| 籌碼 | 千張大戶（持股 1,000 張以上）持股比例比上週增加 | 集保股權分散表 |
| 籌碼 | 投信近 5 日合計買超 | 證交所 T86、櫃買三大法人 |
| 技術 | 趨勢向上：站上關鍵均線、關鍵均線上彎、週線上彎 | 每日收盤行情 |
| 技術 | 回測不破：近 10 日曾回到關鍵均線 2% 內，收盤沒跌破 1% 以上 | 同上 |
| 技術 | 量增突破：收盤創 20 日新高、量 ≥ 1.5 倍均量 | 同上 |

- **波段進場訊號** = 趨勢向上 ＋ 回測關鍵均線不破。關鍵均線可選月線（20 日）或季線（60 日）。
- **均線扣抵**：N 日均線明天會扣掉 N 天前那根收盤。現價高於未來 5 天所有扣抵值顯示「易漲」，代表價格只要守住，均線一週內會持續上彎；全部高於現價顯示「壓力」。點開個股可在 K 線圖上看到週扣、月扣、季扣的位置。
- **錯殺逆勢**：營收年增仍過門檻，但股價距 20 日高點跌 15% 以上，且月線乖離低於 −8% 或 RSI(6) 低於 20。大盤狀態依加權指數單日、5 日、距 20 日高點跌幅判斷為平穩／警戒／恐慌。每檔附上停損（近 5 日低點再下 3%）與反彈到週線、月線的價位。

## 在自己電腦上使用（最簡單）

1. 到 [nodejs.org](https://nodejs.org) 下載安裝 **LTS 版** Node.js（只需要裝一次）。
2. 解壓縮這個專案。
3. **Windows**：雙擊 `start-windows.bat`。**Mac**：打開終端機，輸入 `bash ` 再把 `start.sh` 拖進去，按 Enter。
4. 瀏覽器會自動打開選股畫面，程式同時在背景更新資料。

第一次會自動安裝套件並建立近 4 個月的歷史資料，大約 20–30 分鐘，期間電腦不要睡眠。之後每天收盤後（建議 18:00 以後）打開一次，只補當天資料，幾分鐘就好。用完直接關掉黑色視窗。

幾天沒開也沒關係，下次打開會自動補齊中間缺的交易日（最多往回補 8 個交易日；超過的話到「資料狀態」按「建立／補齊歷史資料」）。

## 安裝與執行（開發者）

需要 Node.js 20 以上。

```bash
npm install
npm run build      # 建置前端
npm start          # 啟動伺服器，開 http://localhost:3000
```

開發時用 `npm run dev`（前端 5173、後端 3000 同時跑）。

### 第一次使用

打開網頁會看到「還沒有資料」，按「建立歷史資料」。系統會抓近 90 個交易日股價、15 日法人、4 個月營收、4 季營益分析與集保資料。證交所 5 秒內超過 3 次請求會被封鎖，所以每次請求間隔 3.5 秒，**全部約 15–25 分鐘**，可以先關掉網頁，跑完名單會自動出現。

也可以用命令列：

```bash
npm run backfill   # 建立歷史資料
npm run update     # 每日更新
npm run diagnose   # 測試每個資料來源抓不抓得到
npm run selftest   # 不連網，用假資料測試整個篩選流程
```

### 千張大戶的歷史資料

集保開放資料只提供「最新一週」。系統每週六自動存一份，累積兩週後就能比較增減。在那之前，系統會針對通過基本面的候選股（最多 150 檔）到集保網站逐檔查詢前 3 週，所以第一天就能用。

## 想放到伺服器上時

- **伺服器要在台灣**。證交所常會擋國外 IP（雲端主機在美國、日本時常拿到「因為安全性考量」頁面）。建議放在自己的電腦、NAS，或台灣機房的 VPS（例如 GCP 台灣 asia-east1）。不能放 Cloudflare Pages 這種只有前端的平台。
- **資料夾要能保存**。`DATA_DIR`（預設 `./data`）放所有累積資料，重新部署時不能被清掉。
- 伺服器一直開著的話，每個交易日 17:40 會自動更新、週六 10:30 抓集保；在自己電腦上用則是每次打開時自動更新。
- 放在公開網址時建議設定 `APP_PASSWORD`，瀏覽器會跳出帳密視窗（帳號隨意）。
- 設定值寫在專案根目錄的 `.env`，範例見 `.env.example`。

## 抓不到資料時

到「資料狀態」頁按「開始檢查」，或跑 `npm run diagnose`。每個來源會顯示正常或失敗原因。

- 證交所／櫃買失敗且訊息提到安全性：換台灣 IP，或等 10–20 分鐘解封。
- 櫃買在 2024 年改版過，程式會同時試新舊兩組網址；如果兩組都失敗，把檢查結果貼給我，我再調整 `server/sources/tpex.js`。
- 觀測站失敗：系統用的是舊版站 `mopsov.twse.com.tw`，如果它下線，月營收仍可從 OpenAPI 每月累積，只是第一次無法回補前幾個月。

## 資料儲存格式

`data/` 底下每個資料集一個資料夾：`prices/YYYYMMDD.json`、`inst/YYYYMMDD.json`、`revenue/YYYY-MM.json`、`margins/YYYYQn.json`（累計數）、`holders/YYYYMMDD.json`，另有 `stocks.json`（名稱、市場、產業）與 `meta.json`（休市日、紀錄）。都是一般 JSON，可以直接打開檢查。
