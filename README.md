# 三重共振選股

找「基本面爆發＋籌碼進駐＋技術面突破」同時成立的台股，另外在大盤恐慌時列出營收仍強、股價卻被錯殺的股票。資料全部來自證交所、櫃買中心、公開資訊觀測站、集保結算所的免費公開資料，抓下來後存在自己的伺服器上累積。

## 篩選邏輯

| 支柱 | 條件（預設，可在畫面左側調整） | 資料來源 |
|---|---|---|
| 基本面 | 近 3 個月營收年增率**每個月**都 > 20% | 證交所／櫃買 OpenAPI 月營收、觀測站回補 |
| 基本面 | 單季毛利率連續 2 季改善（Q-2 < Q-1 < Q） | 營益分析（累計數，系統自動相減還原單季） |
| 籌碼 | 千張大戶（持股 1,000 張以上）持股比例比上週增加 | 集保股權分散表 |
| 籌碼 | 投信近 5 日合計買超 | 證交所 T86、櫃買三大法人 |
| 技術 | 趨勢向上：站上關鍵均線、關鍵均線上彎、週線上彎 | 每日收盤行情 |
| 技術 | 回測不破：近 10 日曾回到關鍵均線 2% 內，收盤沒跌破 1% 以上 | 同上 |
| 技術 | 量增突破：收盤創 20 日新高、量 ≥ 1.5 倍均量 | 同上 |

- **波段進場訊號** = 趨勢向上 ＋ 回測關鍵均線不破。關鍵均線可選月線（20 日）或季線（60 日）。
- **均線扣抵**：N 日均線明天會扣掉 N 天前那根收盤。現價高於未來 5 天所有扣抵值顯示「易漲」，代表價格只要守住，均線一週內會持續上彎；全部高於現價顯示「壓力」。點開個股可在 K 線圖上看到週扣、月扣、季扣的位置。
- **錯殺逆勢**：營收年增仍過門檻，但股價距 20 日高點跌 15% 以上，且月線乖離低於 −8% 或 RSI(6) 低於 20。大盤狀態依加權指數單日、5 日、距 20 日高點跌幅判斷為平穩／警戒／恐慌。每檔附上停損（近 5 日低點再下 3%）與反彈到週線、月線的價位。回測顯示只有在大盤恐慌時逆勢買進才賺錢，大盤平穩或警戒時畫面會提醒只宜觀察。
- **還原權息**：股價、均線、前高、跌幅都用還原權息後的價格計算，除權息那天的跳空不會被當成下跌（最新收盤價不變）。減資、分割、新上市造成的異常跳動（單日超過 10.5%）之前的價格無法比較，不列入計算。
- **千張大戶**要連續幾週都有資料才判斷；中間缺一週時顯示「資料不足」，不會把跨兩週的變化當成一週。

## 國際市場與原物料

「國際與原物料」分頁追蹤 28 項國際指標（資料來源 Yahoo Finance，免費、不需要金鑰）：

| 類別 | 指標 |
|---|---|
| 美股與恐慌指數 | 費城半導體、那斯達克、S&P 500、台積電 ADR、VIX |
| 亞洲股市 | 日經 225、韓國綜合、香港恆生、上證 |
| 匯率與利率 | 美元兌台幣、美元指數、美國 10 年公債殖利率 |
| 能源 | WTI 原油、布蘭特原油、天然氣 |
| 金屬 | 銅、鋁、熱軋鋼捲、鐵礦砂、黃金、白銀 |
| 農產品 | 黃豆、玉米、小麥、原糖、棉花 |
| 運價與綜合 | 散裝航運運價（BDRY）、原物料綜合（DBC） |

- **波動判斷**：每項指標算 1／5／20 日漲跌、趨勢（相對 60 日均線）、近 20 日波動在過去一年的百分位，以及最近一天的漲跌是平常的幾倍標準差。波動高於 80% 的時間或超過 2 倍標準差標「波動偏高」，95% 或 3 倍標「劇烈」，並列在「波動警示」。
- **國際風險燈號**（平穩／警戒／恐慌）：VIX 22／30、費半單日 −3%／−5%、費半 5 日 −6%／−10%、S&P 500 距 20 日高 −8%、台幣 5 日貶 1.2%、美債殖利率 5 日 +25 基點。顯示在頂端大盤列、錯殺逆勢頁與國際頁。
- **產業對應**：塑化↔原油、鋼鐵↔鋼價與鐵礦砂、電線電纜↔銅、航運↔運價與油價、食品↔黃豆玉米小麥糖、電子↔費半與那斯達克等。共振名單裡，所屬產業的相關指標波動偏高時會標示「○○波動大」；個股明細列出相關指標的現況。
- **用 2 年資料驗證**：國際燈號出現後台股當天與之後 5 天的表現；各產業和各指標每週漲跌的相關係數（實際連動強弱）；國際平穩／警戒、費半在季線上下對各策略的影響（在「策略績效」的濾網表）。
- 美股、期貨在台股收盤後才收盤，台股隔天才反應，所以 GitHub 另外在週一到週五早上 07:20 更新國際行情，開盤前就能看到。本機版則是 `CRON_GLOBAL`（預設 07:20）或執行 `node server/cli.js global`。

## 用手機看（GitHub 自動更新，推薦）

這個 repo 已經設定好 GitHub Actions（`.github/workflows/daily.yml`）：

- 每個交易日台北時間 18:40、週六 10:30，GitHub 會自動抓證交所、櫃買、觀測站、集保資料，存回 repo 的 `data/` 資料夾；每個交易日早上 07:20 另外更新國際行情。
- GitHub 的排程常常延遲好幾個小時、偶爾沒跑，所以另外排了備援時間（晚上 20:40、23:10，早上 08:10，週六 12:30）。`server/should-run.js` 會先檢查今天是否已經更新過，做過就在 10 秒內結束。
- 接著把選股畫面發布到 GitHub Pages：**https://chung38.github.io/stock-screener/**，用手機瀏覽器打開即可，篩選條件一樣可以調。
- 第一次執行會自動建立近 4 個月的歷史資料，大約 30–40 分鐘。
- 想立刻更新：repo 的 Actions 分頁 →「每日更新」→ Run workflow。勾選「重新補齊」會重抓 4 個月。
- repo 必須是 Public 才能免費使用 GitHub Pages（篩選結果與資料都會公開）。

不用開電腦，也不用伺服器。

## 突破策略與回測

「突破策略」分頁把下面這套規則寫成程式，並用歷史資料檢查：

- 收盤突破前 20 日（或 60、120 日）最高價，而且前一天還沒突破（新的突破）。
- 突破當天成交量 ≥ 前 20 日均量的 1.5 倍（可改 2、3 倍或不限）。
- 突破後連續 2 天收盤都沒跌回前高才算站穩，站穩那天收盤進場。

**今日突破訊號**列出近 5 個交易日內符合的股票，標示「站穩 N 天」或「觀察中」，也會標出同時在共振名單裡的股票。

**回測**比較六組條件（A 只看突破、B 加量能、C 加量能＋站穩、D 量 2 倍、E 60 日前高、F 120 日前高），列出交易次數、隔日上漲比例、5／10／20 日平均報酬與勝率、假突破率，並和「任意一天買進」的對照組比較。另外依量比、突破幅度、收盤位置（上影線）、個股與大盤是否在季線上分組，看哪些情況最容易假突破；也依季別看不同市場環境的表現，並列出最近 40 筆實際案例方便核對。

- 報酬已扣來回成本 0.785%（手續費 0.1425%×2 不打折、證交稅 0.3%、滑價 0.1%×2）。
- 同一檔 10 個交易日內只算第一次突破；只算 20 日均量 300 張以上、股價 10 元以上。
- 假突破＝進場後 5 天內收盤跌回前高。
- 股價已還原權息；沒有計入漲跌停買不到、下市股票。這一頁以確認當天收盤價進場，比較樂觀；「策略績效」頁用隔天開盤進場。
- 大盤在季線之下時，畫面會提醒：回測中這時候的突破訊號平均是虧損的。
- 想要 2 年的歷史：GitHub Actions →「每日更新」→ Run workflow，勾選「補齊近 2 年股價」（約 60–90 分鐘，只需要一次）。本機則執行 `PRICE_DAYS=500 npm run backfill`。

## 策略績效（哪些方法真的賺錢）

「策略績效」分頁用約 2 年的資料，比較突破前高、回測均線、錯殺逆勢、三重共振，以及 KD、MACD、RSI、布林通道、均線交叉、外資／投信連買等坊間常用指標：

- 訊號在收盤後產生、隔天開盤進場；每筆扣來回成本（當沖證交稅減半）；月營收、季報依法定公布日之後才使用，不偷看未來。
- 前 2/3 期間挑參數（樣本內），後 1/3 期間驗證（樣本外），並和「隨機挑股票同樣持有」比較。
- 「短線持有」表比較當沖、3／5／10 天，並模擬最多同時 10 檔的帳戶，換 20 種挑股順序取中位數，和同期間大盤比較。
- 第一次需要補齊 2 年資料：GitHub Actions →「每日更新」→ Run workflow，勾選「補齊近 2 年股價」與「補齊 2 年月營收、毛利率、法人資料」各一次；除權息資料另跑一次「除權息資料」。之後每日更新會自動接續。

## 在自己電腦上使用

1. 到 [nodejs.org](https://nodejs.org) 下載安裝 **LTS 版** Node.js（只需要裝一次）。
2. 解壓縮這個專案。
3. **Windows**：雙擊 `start-windows.bat`。**Mac**：打開終端機，輸入 `bash ` 再把 `start.sh` 拖進去，按 Enter。
4. 瀏覽器會自動打開選股畫面，程式同時在背景更新資料。

第一次會自動安裝套件並建立近 4 個月的歷史資料，大約 20–30 分鐘，期間電腦不要睡眠。之後每天收盤後（建議 18:00 以後）打開一次，只補當天資料，幾分鐘就好。用完直接關掉黑色視窗。

幾天沒開也沒關係，下次打開會自動補齊上次更新之後缺的交易日（幾週沒開也會補；超過一年才需要到「資料狀態」按「建立／補齊歷史資料」）。

## 安裝與執行（開發者）

需要 Node.js 20 以上。

```bash
npm install
npm run build      # 建置前端
npm start          # 啟動伺服器，開 http://localhost:3000
```

開發時用 `npm run dev`（前端 5173、後端 3000 同時跑）。

### 第一次使用

打開網頁會看到「還沒有資料」，按「建立歷史資料」。系統會抓近 90 個交易日股價、15 日法人、4 個月營收、4 季營益分析與集保資料。證交所 5 秒內超過 3 次請求會被封鎖，所以每次請求間隔 3.5 秒，**全部約 15–25 分鐘**，可以先關掉網頁，跑完名單會自動出現。

也可以用命令列：

```bash
npm run backfill       # 建立歷史資料（PRICE_DAYS=500 可補約 2 年）
npm run update         # 每日更新
npm run research-data  # 補齊 2 年月營收、營益分析、法人（策略研究用）
npm run dividends      # 重抓近 28 個月除權息資料
npm run research       # 跑策略研究，輸出 dist/research.json
npm run diagnose       # 測試每個資料來源抓不抓得到
npm run selftest       # 不連網，用假資料測試整個篩選流程
```

### 千張大戶的歷史資料

集保開放資料只提供「最新一週」。系統每週六自動存一份，累積兩週後就能比較增減。在那之前，系統會針對通過基本面的候選股（最多 150 檔）到集保網站逐檔查詢前 3 週，所以第一天就能用。

## 想放到伺服器上時

- **伺服器要在台灣**。證交所常會擋國外 IP（雲端主機在美國、日本時常拿到「因為安全性考量」頁面）。建議放在自己的電腦、NAS，或台灣機房的 VPS（例如 GCP 台灣 asia-east1）。不能放 Cloudflare Pages 這種只有前端的平台。
- **資料夾要能保存**。`DATA_DIR`（預設 `./data`）放所有累積資料，重新部署時不能被清掉。
- 伺服器一直開著的話，每個交易日 17:40 會自動更新、週六 10:30 抓集保；在自己電腦上用則是每次打開時自動更新。
- 放在公開網址時建議設定 `APP_PASSWORD`，瀏覽器會跳出帳密視窗（帳號隨意）。
- 設定值寫在專案根目錄的 `.env`，範例見 `.env.example`。

## 抓不到資料時

到「資料狀態」頁按「開始檢查」，或跑 `npm run diagnose`。每個來源會顯示正常或失敗原因。

- 證交所／櫃買失敗且訊息提到安全性：換台灣 IP，或等 10–20 分鐘解封。
- 櫃買在 2024 年改版過，程式會同時試新舊兩組網址；如果兩組都失敗，把檢查結果貼給我，我再調整 `server/sources/tpex.js`。
- 觀測站失敗：系統用的是舊版站 `mopsov.twse.com.tw`，如果它下線，月營收仍可從 OpenAPI 每月累積，只是第一次無法回補前幾個月。
- 某個月的營收或某一季的營益分析只抓到一部分（家數比其他期別少一成以上）時，下次更新會自動重抓。

## 資料儲存格式

`data/` 底下每個資料集一個資料夾：`prices/YYYYMMDD.json`、`inst/YYYYMMDD.json`、`revenue/YYYY-MM.json`、`margins/YYYYQn.json`（累計數）、`holders/YYYYMMDD.json`，另有 `global.json`（國際指標日收盤，約 2 年）、`stocks.json`（名稱、市場、產業）、`dividends.json`（除權息：日期、除權息前收盤價、參考價）與 `meta.json`（休市日、紀錄）。都是一般 JSON，可以直接打開檢查。
